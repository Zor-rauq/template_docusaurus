# Conventions

> À compléter au fur et à mesure avec les conventions adoptées (nommage, structure de commits,
> style de code, arborescence de projet...).

## Nommage

- Branches Git : `type/description-courte` (ex. `feat/ajout-page-procedures`).
- Commits : préfixe court (`feat`, `fix`, `docs`, `chore`...) suivi d'un résumé à l'impératif.

## Documentation

- Un fichier Markdown = un sujet.
- Les modèles de fiches se trouvent dans chaque famille (`fiche-technologie`, `runbook`,
  `checklist`, `adr`, `postmortem`).
- Toujours dater les documents (`AAAA-MM-JJ`).

## Structure des dossiers

Voir l'arborescence `docs/` de ce projet, organisée selon les 5 familles Docs as Code.
