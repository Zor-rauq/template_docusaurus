# Glossaire

> Définitions des termes, acronymes et concepts rencontrés régulièrement.

| Terme | Définition |
|---|---|
| **Docs as Code** | Approche consistant à traiter la documentation comme du code source : Markdown, Git, revue par Pull Request, publication automatisée. |
| **ADR** | *Architecture Decision Record* — document court qui capture une décision d'architecture, son contexte et ses conséquences. |
| **Runbook** | Procédure pas à pas pour réaliser une opération technique. |
| **Postmortem** | Analyse rédigée après un incident, visant à en comprendre la cause et à en tirer des actions correctives. |
