# Cartographie

Objectif : **inventorier ce qui existe**. Cette famille répertorie les services, outils,
librairies et technologies rencontrés, pour savoir rapidement "qu'est-ce qui tourne, avec quoi,
et où en trouver la fiche".

Une fiche de cartographie répond en général à :

- **Quoi** : nom, catégorie (langage, framework, outil CLI, service SaaS...).
- **Pourquoi** : dans quel contexte cette technologie a été rencontrée ou adoptée.
- **Où** : liens vers la documentation officielle, le dépôt, l'environnement concerné.
- **Statut** : découverte, en test, adoptée, dépréciée.

## Contenu de cette section

- [Modèle de fiche technologie](./fiche-technologie) — à dupliquer pour chaque nouvelle
  technologie découverte.

## Bonnes pratiques

- Une fiche = une technologie ou un outil.
- Mettre à jour le **statut** quand l'usage évolue (découverte → adoptée / abandonnée).
- Toujours indiquer la **date de découverte** pour garder une frise chronologique implicite.
